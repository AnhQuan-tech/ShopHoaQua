# 🍎 Fruit Paradise - Shop Bán Hoa Quả Tươi Sạch & WordPress Admin CMS

Website thương mại điện tử chuyên nghiệp bán hoa quả tươi sạch cao cấp nhập khẩu và đặc sản nội địa, tích hợp giao diện quản trị **WordPress Admin CMS** (tài khoản: `admin` / mật khẩu: `admin`), hệ thống **Plugins** tùy biến và các **Popups quảng cáo marketing sinh động**.

---

## 🚀 Tính Năng Nổi Bật

### 1. Giao Diện Cửa Hàng (Storefront)
- **Top Bar & Ticker**: Thanh chạy chữ Flash Sale & thông báo freeship đơn từ 300k.
- **Hero Slider Banner**: Trình chiếu ảnh hoa quả 4K sắc nét, bắt mắt.
- **Giờ Vàng Giá Sốc (Flash Sale)**: Đồng hồ đếm ngược từng giây kèm thanh tiến độ bán hàng.
- **Lưới Hoa Quả & Tìm Kiếm**: Lọc theo danh mục (Nhập khẩu, Nội địa, Giỏ quà VIP, Nước ép detox), tìm kiếm thời gian thực.
- **Modal Chi Tiết Hoa Quả**: Xem ảnh phóng to, bảng dinh dưỡng, độ ngọt Brix, xuất xứ, cam kết bao ăn 1 đổi 1.
- **Giỏ Hàng & Thanh Toán**:
  - Giỏ hàng trượt với thanh đo freeship tự động.
  - Áp dụng mã giảm giá (`HOAQUA50`, `FREESHIP`, `VIP100`).
  - Thanh toán linh hoạt: Tiền mặt COD hoặc quét mã VietQR / MoMo sinh mã QR động.
  - Hiệu ứng pháo hoa Confetti chúc mừng đặt hàng thành công.

### 2. Hệ Thống Plugins & Popups Quảng Cáo
- **WP Fruit Marketing Popup Pro**: Popup quảng cáo giảm 50% tặng kèm voucher khi vào trang.
- **WP Social Proof Live Orders**: Thông báo đơn hàng khách mua nhảy liên tục góc dưới bên trái màn hình.
- **WP Lucky Spin Wheel**: Vòng quay may mắn trúng voucher, freeship và dâu tây miễn phí.
- **WP Fruit & Leaf Falling Animation**: Hiệu ứng dâu tây 🍓, lát cam 🍊, lá xanh 🍃 rơi bồng bềnh lãng mạn.
- **WP Floating Contact & Zalo**: Cụm nút nổi hotline và chat Zalo tư vấn giỏ quà.
- **WP Top Flash Sale Countdown Bar**: Thanh thông báo ưu đãi ghim đầu trang.

### 3. Trang Quản Trị WordPress CMS (WP-Admin)
- **Đăng nhập WP**: Giao diện đăng nhập chuẩn WordPress (`admin` / `admin`).
- **Dashboard**: Thống kê doanh thu, đơn hàng mới, số lượng hoa quả, cảnh báo tồn kho thấp.
- **Sản Phẩm (WooCommerce Style)**: Thêm, sửa, xóa hoa quả, quản lý giá bán, tồn kho.
- **Đơn Hàng (Orders)**: Xem danh sách đơn, cập nhật trạng thái đơn (Chờ xử lý, Đang giao, Hoàn thành, Đã hủy).
- **Quản Lý Plugins**: Bật / Tắt và cấu hình nội dung cho từng plugin.
- **Cài Đặt Hệ Thống (Settings)**: Thay đổi tên shop, hotline, địa chỉ, phí ship, thêm mã voucher và đổi mật khẩu admin.

## 🛠️ Cài Đặt & Chạy Dự Án

1. **Cài đặt thư viện:**
   ```bash
   npm install
   ```

2. **Khởi chạy ứng dụng (Backend Express + Frontend Vite):**
   ```bash
   npm run dev
   ```
   Website sẽ chạy tại: [http://localhost:3000](http://localhost:3000)

3. **Tài khoản quản trị viên WordPress:**
   - **Tài khoản:** `admin`
   - **Mật khẩu:** `admin`
